# ぽかぽか島 🍃

ネットで誰でも入れる、のんびりした島のミニメタバースです。
ブラウザで開いて名前とどうぶつを選ぶと、同じURLを開いた人どうしで同じ島を歩きまわれます。

## できること

- **主人公はロボットの MOMO**：島にくる人は みんなテレビ頭のロボット MOMO になります。
  無料プランの MOMO はミント色で、アクセントの色（10色）を選べるのは有料プランの人だけです。
  支払いのしくみはまだないので、いまは全員が無料プランです（判定は `public/app.js` と `server.js` の `isPremium()`）。
  MOMO は電子音でしゃべります。
- **おしゃべり**：Enter で入力すると頭の上にふきだしが出て、どうぶつ語っぽい声でしゃべります（近い人ほど大きく聞こえます）。
- **リアクション**：👋 😊 😢 💢 ❗ 💤 ❤️ 🎵（キーボードの 1〜8 でも）。
- **木をゆらす**：実のなる木（もも・りんご・オレンジ・なし・さくらんぼ）をゆらすと果物が落ちてきて、拾うとポケットに入ります。
  たまにポカぶくろ（島のお金「ポカ」）も。落ちたものは、上を歩くか、クリック／タップすると拾えます。落ちた果物や木の実の状態は、島にいる全員で共有されます（3分でまた実ります）。
- **家に入る**：6軒の家のドアに向かって歩くと中に入れます。家ごとに壁紙や家具の色がちがいます。
  同じ家に入った人どうしは、中で会えます。出口のマットで下へ歩くと外に出ます。
  ソファ（2人分）といすには すわれて、ベッドでは ねころべます（E キー、歩き出すと立ちあがります）。
- **地図**：左上に島の地図と、いまいる場所（「ひろば」「あかい屋根の家のまえ」など）が出ます。
  矢印が自分、色つきの点がほかの人、黄色の点が住民です。タップか M キーで大きくなります。
- **住民の こむぎ**：島を おさんぽしているハムスター。話しかけると、時間に合わせたあいさつや島のヒントを教えてくれます。
  どこを歩いているかは時刻で決まるので、サーバーがなくても全員の画面で同じ場所にいます。
- **本物の時間とつながった島**：空の色・家の窓あかり・街灯・BGM が、あなたの時計といっしょに朝・昼・夕方・夜と変わります。
  BGM は1時間ごとにメロディと調が変わります。
- **島のようす**：まん中の広場と大きな木、けいじばん、川と橋、池、砂浜のヤシの木、6軒の家、花だん、ちょうちょ。
  遠くの地面がなだらかに下へ曲がって見える「転がる丸太」のような見え方にしています。
- スマホでも遊べます（左下のスティックで移動、A ボタンでアクション、2本指でズーム）。

画像・音・3D モデルのファイルは使っていません。地形も家もキャラクターも音楽も、すべてコードで作っています。

## 操作

| キー | 動作 |
| --- | --- |
| WASD・矢印キー | あるく（Shift でかける） |
| クリック／タップ | その場所まであるく |
| E・スペース | 木をゆらす／ひろう／はなす／家に入る・出る／けいじばんを読む |
| M | 地図を大きくする |
| Enter | おしゃべり |
| 1〜8 | リアクション |
| ホイール | ズーム |

## 手元で動かす

Node.js 18 以上が必要です。

```sh
cd village
npm install
npm start
# → http://localhost:3000/
```

同じ Wi‑Fi の友だちなら `http://<あなたのPCのIPアドレス>:3000/` で入れます。

## ネットに公開する（誰でも入れるようにする）

### Render（無料プランあり・おすすめ）

1. [Render](https://render.com) に GitHub でログインします。
2. **New → Blueprint** から このリポジトリを選びます。ルートの `render.yaml` が読まれて、`village/` がそのまま Web サービスになります。
3. できあがった `https://pokapoka-island-xxxx.onrender.com/` を友だちに送れば、みんなで同じ島に入れます。

無料プランは しばらく誰もいないと眠るので、最初に開いたときは起きるまで数十秒かかります。
そのあいだは ひとりモードで島が開き、サーバーが起きた時点で自動的に みんなの島へ切り替わります。

### ほかの方法

- **Railway / Fly.io / VPS など**：`village/` で `npm ci && npm start` が動く環境ならどこでも動きます（`PORT` 環境変数に対応）。
- **いま手元で動いているものを一時的に公開**：`npx cloudflared tunnel --url http://localhost:3000` で出る URL を送ります。

### 画面とサーバーを分けて置く

画面（`village/public/`）だけを GitHub Pages などに置き、サーバーを別の場所で動かすこともできます。
その場合は `?server=wss://サーバーのホスト名` を付けて開きます。

```
https://<ユーザー名>.github.io/<リポジトリ>/village/public/?server=wss://pokapoka-island-xxxx.onrender.com
```

## つながり方

`public/net.js` が、開いた場所に合わせて自動で選びます。

1. **サーバー**：`server.js` の WebSocket（`/ws`）。位置・おしゃべり・リアクション・木の実を中継します。
2. **claude.ai の Artifact として開いたとき**：同じページを開いている人どうしで島を共有します（サーバー不要）。
3. **どちらもないとき**：ひとりモード。サーバーが見つかりしだい、みんなの島へ切り替わります。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `server.js` | 静的ファイルの配信と WebSocket の中継（依存は `ws` だけ） |
| `public/index.html` | 画面の部品と見た目（CSS） |
| `public/app.js` | 島づくり・プレイヤー操作・カメラ・昼夜・通信の受け取り |
| `public/world.js` | 島の形・川・池・橋・家・木の配置と、家の中の部屋（決まった乱数なので、誰の画面でも同じ島） |
| `public/villager.js` | MOMO と、住民のどうぶつ（すわる・ねころぶ・手をふる などの動きも） |
| `public/resident.js` | 住民こむぎの おさんぽルートと会話 |
| `public/gfx.js` | 地面が奥へ曲がって見えるシェーダーと、やわらかいセル調のマテリアル |
| `public/audio.js` | どうぶつ語・効果音・時間で変わる BGM（WebAudio で合成） |
| `public/net.js` | 3通りのつながり方 |

## 開発用

- `?hour=21` を付けると、その時刻の空で表示します（例：`?hour=6` で夜明け、`?hour=18.5` で夕焼け）。
