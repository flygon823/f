# 月と潮の磯 / MOONLIT TIDEPOOL

> 🍃 みんなで入れる島のミニメタバース **ぽかぽか島** は [`village/`](village/) にあります。
> ボタン1つでネットに公開できます： [![Render に公開する](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/flygon823/f)

磯の潮だまりを小さな惑星のように眺める、3D の海の生き物図鑑です。
北半球が南国の磯、南半球が冬の流氷の海で、赤道で2つの海がつながっています。
ブラウザで `index.html` を開くだけで動きます（Three.js は CDN から読み込みます）。

## できること

- **潮の満ち引き**：スライダーで干潮〜満潮を動かすと、海面・潮だまり・濡れた砂・波打ち際の泡が変わります。
  「自動で眺める」で潮が満ち引きし、カメラもゆっくり回ります。
- **視点の切り替え**：海辺（全景）／潮だまり（寄り）／水中（海の中から見上げる）。
- **生き物をクリック**：名前・学名・解説と、潮位に合わせて変わる「いまの様子」を表示します。
  クリックするとカニがはさみを振り上げたり、ヤドカリが殻に引っこんだり、タコが色を変えたりします。
- **時間帯の移り変わり**：開いたときの現在時刻から始まり、箱庭の中の1日が約8分で過ぎていきます。
  夜明け・朝・昼・午後・夕暮れ・夜で空の色と光が変わり、太陽は東から西へ動いて影の向きも変わります。
  夜は月明かりだけになり、波打ち際が夜光虫で青く光ります。右上の時刻スライダーで好きな時間に動かせます。
- **3D モデルの販売**：解説カードの「この 3D モデルを BOOTH で見る」から、Moonlit Props の「磯の生き物 3D セット」（FBX / GLB / Blender）のページへ移動できます。
- **裏側はオホーツクの海**：惑星をドラッグして南半球まで回すと、オホーツク海（北海道）が見えます。見ている側に合わせて、タイトル・生き物の一覧・季節のボタンが自動で切りかわります。
  北の南国の海から南の冷たい海へ、海の色は少しずつ変わり、境目の線はありません。
- **四季（オホーツク側）**：時計パネルの「春・夏・秋・冬」で季節を進められます（開いたときは今日の日付の季節）。
  冬は雪と流氷・ゴマフアザラシ・クリオネ・オオワシ、春は雪どけとエゾヤマザクラ、夏はハマナスとウミネコ、
  秋は紅葉・ナナカマドの赤い実・シロザケ。「自動で眺める」中は1年が約4分で巡ります。
- **流氷の流れ**：湾をめぐる反時計回りの海流にのって、流氷がゆっくり回ります。水面の白い筋が流れを表します。
  干潮では浜の氷が取り残されます。
- **ぽかぽか島からのなかま**：`village/` のぽかぽか島から、MOMO（テレビ頭のロボット）が磯の観察にやってきます。
  島のどうぶつは、北海道の野生のなかまとして出てきます（くま→エゾヒグマ、うさぎ→エゾユキウサギ、
  こむぎと同じほおぶくろを持つエゾシマリス）。南の花畑にはツマベニチョウが飛びます。
- **生き物の目線**：解説カードの「目線で見る」で、その生き物の目の高さから世界を見られます。
  生き物が動くと景色もいっしょに動き、ドラッグで見回せます。「もとにもどる」か Esc でもどります（動き回る生き物だけ。植物・流氷・イソギンチャク・止まっている鳥はのぞく）。
- **宇宙**：惑星のまわりは本物の宇宙のように、いつも黒い空に星と天の川。太陽は宇宙の決まった場所にあり、時刻が進むと惑星のまわりを回るので、
  太陽の側が昼、反対側が夜になります（表が昼のとき裏は夜）。大気は昼の側で青く、昼と夜の境目でオレンジに光ります。
  月は太陽に照らされた球で、今日の月齢どおりの形（満ち欠け）で昇り沈みします。地面近くまで降りると、大気の中なので空が青や夕焼け色になります。
- **空の層**：惑星のまわりの空にも、高さごとに動くものがいます。低い空には鳥の群れ（南の海にエリグロアジサシ、北の海には9月下旬〜4月にオオハクチョウのV字の列）、
  その上を飛行機雲を引く旅客機、さらに高いところを国際宇宙ステーション、いちばん遠くに赤道の上で止まって見える気象衛星ひまわり。
  クリックすると解説が出ます（鳥は目線でも見られます）。夜は旅客機のランプが点滅し、宇宙ステーションが星のように光ります。
- **めずらしい生き物**：ときどき、赤道近くの外洋にザトウクジラ（潮吹き・ブリーチング・尾びれを上げて潜る）、アオウミガメ、
  オホーツク側にはシャチの家族の群れが姿を見せます。現れると画面下に「めずらしい！」とお知らせが出て、「見にいく」でそばへ飛べます。
- **空のできごと**：ときどき空模様や災害が起きます。出やすさは現実の頻度の比率に合わせ、時間だけ縮めています。
  - 虹：朝や夕方（太陽が42°より低いとき）、にわか雨のあとに太陽と反対側へ。南国ではよく、北海道は暖かい季節だけ。外側にうすい副虹も出ます。
  - 台風：南国側だけ、7〜10月に多く、冬は来ません。渦を巻く雲が海をわたり、島に近づくと暗くなって雨と風が強まり、草が大きくなびきます。
  - 竜巻（水上竜巻）：暖かい季節の昼間に、まれに海の上で。
  - オーロラ：オホーツク側の暗い夜だけ、めったに出ません（春分・秋分のころと冬は少し出やすい）。
  - 流れ星：夜の側の大気で燃える流れ星がときどき。1月・8月・12月の流星群の日は多くなります。
  現れると画面下にお知らせが出て、「見にいく」でそばへ飛べます。
- **生き物の種類**：どの生き物にも近い仲間が2種ずついて、全部で75種ほど（南国の磯、オホーツク、空、めずらしい生き物）。
  画面下の名前は「タコ」「カニ」「アザラシ」のようななかまごとにまとめ、押すとその中の種類が上に並びます。
  季節で来る・いなくなる種類（ユリカモメは冬、カラフトマスは夏の終わり、エゾモモンガは夜など）も現実に合わせています。
- **個体差**：同じ種類の中にも、ふつうの色・色の濃い個体（キタキツネは黒っぽい十字ギツネ）・小さな子どもや若鳥が混ざります。
  解説カードの分類のところに「子ども」「若鳥」などと出ます。
- **ぷくぷく**：磯の沖の水の中に、すきとおった丸い体のふしぎな住人が8匹。紫・水色・黄色・ピンク・緑など色も顔もそれぞれで、ふわふわただよいながら見ている人のほうを向きます。夜はほんのり光ります（「水中」の視点か、下の「ぷくぷく」で会えます）。
- **選択の解除**：選んでいる生き物の名前をもう一度押すと（または × か Esc）、選択が外れて選ぶ前の視点にもどります。
- **画面**：時刻・季節・潮の操作と視点ボタンは右上のパネルにまとめ、解説カードもその下に出ます（スマホでは下）。
  惑星の前をふさがないよう、下には生き物の名前だけを置いています。
- **回転**：ドラッグで惑星をどの向きにも回せます（上下で止まりません）。回転の軸はいつも惑星の中心で、生き物に寄っているときも変わりません。手を離すと少し惰性で回ります。
- **潮で変わるふるまい**：ウメボシイソギンチャクは水につかると触手を広げ、潮が引くと丸く縮みます。
  満潮になるとタコやメジナの群れが岩場の上まで出てきます。

## 登場する生き物

マダコ／アゴハゼ／イソガニ／ホンヤドカリ／ウメボシイソギンチャク／ムラサキウニ／イトマキヒトデ／メジナ（幼魚）

## 操作

- ドラッグ：回転、スクロール／ピンチ：拡大縮小、右ドラッグ：移動
- Esc：解説カードを閉じる

## ローカルで開く

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```

地形・岩・植物・生き物はすべてコードで生成しているので、画像や 3D モデルのファイルは不要です。
